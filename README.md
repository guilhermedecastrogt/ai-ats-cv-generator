# AI CV Generator

Generate targeted, ATS-friendly, one-page CVs using AI — tailored per role, compiled to PDF with LaTeX.

Built for software engineers applying to multiple roles across different stacks and markets. Instead of maintaining 10 different Word documents, you keep one source of truth and let the AI do the tailoring.

---

## How It Works

```
context/          ← You fill these in (your real info)
  aboutme.md      ← Main profile: jobs, skills, education, projects
  linkedin.md     ← Optional: extra detail from LinkedIn
  github.md       ← Optional: technical depth on your projects
  target-roles.md ← Which CV variants you want

CLAUDE.md         ← Instructions the AI follows automatically

output/           ← AI writes here; compile.py builds the PDFs
  backend/
    cv_backend.tex
    cv_backend.pdf
    summary.md
  fullstack/
    ...
```

You fill in your info → tell the AI to generate → compile to PDF. Done.

## Quick Start

### 1. Prerequisites

**LaTeX compiler** (for PDF generation):

| OS | Command |
|----|---------|
| macOS | `brew install --cask mactex-no-gui` |
| Ubuntu/Debian | `sudo apt-get install texlive-full` |
| Windows | Install [MiKTeX](https://miktex.org/download) |

After installing on macOS, run once: `eval "$(/usr/libexec/path_helper)"`

**AI editor** — any of these work:
- [Claude Code](https://claude.ai/code) (recommended — reads CLAUDE.md automatically)
- Cursor, Windsurf, or any editor with Claude/GPT integration

---

### 2. Fill In Your Information

Open the `context/` folder and fill in the files you find there. Each file has instructions inside explaining what to paste.

The AI reads **every file** inside `context/` — regardless of filename or extension. You can add as many files as you want:

| File | What to put there |
|------|------------------|
| `context/aboutme.text` | Your professional profile, current CV, or bio |
| `context/linkedin.text` | LinkedIn export or copy-paste from your profile |
| `context/github.text` | GitHub report generated by an AI with web search |
| `context/currently-gupy.text` | Job description you are applying to right now |
| Any other file | Notes, role preferences, technologies to emphasize, etc. |

Use your real information only. The AI will not invent experience, metrics, or certifications.

---

### 3. Generate Your CVs

Open this folder in Claude Code (or your AI editor) and send one of these prompts:

```
Generate all my CVs based on my context files.
```

```
Generate a tailored CV for this job posting: [paste job description]
```

```
Update my backend CV — I just added a new job at Company X.
```

The AI reads your context, generates a `.tex` file per variant under `output/`, and writes a `summary.md` explaining every tailoring decision.

---

### 4. Compile to PDF

```bash
python3 compile.py
```

This finds every `.tex` under `output/`, compiles each to PDF (twice, to resolve references), and cleans up auxiliary files.

If packages are missing:
```bash
# macOS
sudo tlmgr update --self && sudo tlmgr install titlesec enumitem collection-latexrecommended

# Ubuntu
sudo apt-get install texlive-full
```

## CV Variants

The variants you generate depend on what you put in `context/target-roles.md`. Common examples:

| Folder | Role |
|--------|------|
| `output/backend/` | Backend Developer |
| `output/fullstack/` | Full Stack Developer |
| `output/devops/` | DevOps / Platform Engineer |
| `output/frontend/` | Frontend Developer |
| `output/python/` | Python Developer |
| `output/general/` | General Software Engineer |
| `output/tailored/company-name/` | Custom CV for a specific job posting |

You can ask the AI for any variant — just describe the role.

## Applying to a Specific Job

Paste the job description directly into your AI chat:

```
Generate a tailored CV for this role at Stripe:
[paste full job description here]
```

The AI will:
1. Identify the keywords and requirements
2. Reorder your experience to match
3. Rewrite bullet points to use the job's language (ATS optimization)
4. Save to `output/tailored/stripe/`

---

## What the AI Will NOT Do

- Invent experience, dates, metrics, or certifications
- Exceed one page
- Add "(in progress)" to your education (see CLAUDE.md for why)
- Generate a CV without writing a `summary.md` explaining its decisions

## Tips

- **Keep `aboutme.md` up to date.** Every time you start a new job, get a certification, or ship a notable project, add it here. Then ask the AI to regenerate.

- **Use metrics whenever possible.** "Reduced API latency by 40%" is far more effective than "improved performance." The AI can only use what you give it — be specific.

- **One source of truth.** Never edit the `.tex` files directly. Edit your context files and regenerate. This way all variants stay in sync.

- **For each application, generate tailored.** A 15-minute AI tailoring session per application beats sending the same generic CV everywhere.

- **Review the `summary.md`.** The AI explains every decision it made. This helps you understand why certain things were included or excluded, and gives you talking points for interviews.
